# Tours and Travel Management System

## Overview

The Tours and Travel Management System is a full-stack web application designed to simplify tour package management, booking, and travel operations.

The application enables customers to browse tour packages, book tours, make secure payments, and manage their bookings. It also provides dedicated dashboards for administrators and travel agents to manage tour packages, customers, bookings, and payments.

The backend is primarily built using Java Spring Boot following a microservices architecture, with a separate ASP.NET Core microservice for centralized logging.

## Getting Started

### Prerequisites

- Java 17+
- Maven
- Node.js
- MySQL
- Git

### Installation

1. Clone the repository

```bash
git clone https://github.com/Shra321/Tours-and-Travel-Management-System.git
```

2. Configure the MySQL database.

3. Start the backend services.

4. Start the React frontend.

5. Access the application in your browser.
