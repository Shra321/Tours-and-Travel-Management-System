# Project Overview

## Description

The Tours and Travel Management System is a full-stack web application designed to simplify tour package management, booking, and travel operations.

The system follows a microservices architecture with Java Spring Boot as the primary backend and a dedicated ASP.NET Core microservice for centralized logging.

## Modules

- Authentication
- Tour Package Management
- Booking Management
- Payment Management
- Customer Management
- Agent Management
- Admin Dashboard

## Architecture

- React.js
- Spring Boot
- MySQL
- REST APIs
- JWT Authentication
- Logging Microservice (.NET)
